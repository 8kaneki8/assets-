# موقع مسابقات مؤسسة إحياء

موقع عربي تفاعلي لإدارة مسابقة بين فريقين.

## التشغيل
افتح `index.html` في المتصفح مباشرة. لا يحتاج إلى تثبيت أو خادم.

## المميزات
- فريقان مع لوحة نقاط ودور متغير.
- قرعة عشوائية لتحديد الفريق الذي يبدأ.
- فئات وأسئلة بقيم 100 إلى 500 نقطة.
- إظهار الإجابة، احتساب النقاط، وتمرير الدور عند الخطأ.
- لوحة تحكم لتعديل أسماء الفرق والفئات والأسئلة.
- حفظ حالة المسابقة محليًا في المتصفح عبر Local Storage.

## النشر
يمكن نشر محتويات هذا المستودع عبر GitHub Pages بعد دمج التغييرات وتفعيل Pages من إعدادات المستودع.

الشعار يُحمّل من ملف PNG الموجود في جذر المستودع.
